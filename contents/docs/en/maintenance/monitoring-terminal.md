---
title: Monitoring & Web Terminal
description: Real-time container metrics, live logs inspection, and full interactive xterm.js web terminal.
---

Nitrobase provides integrated observability tools:
* **Interactive Web Terminal:** Full PTY terminal powered by **xterm.js** and WebSockets directly in your browser.
* **Live Log Stream:** Follow standard output and error streams of running containers.
* **Resource Metrics:** Track CPU usage, RAM utilization, disk I/O, and network transfer.
