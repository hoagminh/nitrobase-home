---
title: Đồng bộ từ Supabase Cloud (Cloud Sync)
description: Nhập toàn bộ database, file lưu trữ và edge functions từ Supabase Cloud về máy chủ riêng.
---

Chuyển đổi dữ liệu dễ dàng từ Supabase Cloud về máy chủ của bạn mà không cần xuất SQL thủ công.

1. Lấy chuỗi kết nối và Service Role Key từ dự án Supabase Cloud.
2. Lưu thông tin tại **Settings -> Cloud Connections**.
3. Vào **Apps -> New App -> Import from Supabase Cloud**.
4. Nitrobase sẽ kết nối bảo mật qua TLS, đồng bộ schema database, chuyển toàn bộ file Storage và khởi chạy bản self-hosted tự động.
