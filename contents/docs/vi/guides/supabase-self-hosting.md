---
title: "Hướng dẫn chuyên sâu: Tự host Supabase"
description: Hướng dẫn đầy đủ tự host toàn bộ ngăn xếp Supabase trên VPS riêng với Nitrobase.
---

Nitrobase hỗ trợ tối ưu và chuyên sâu nhất cho hệ sinh thái Supabase:
* **PostgreSQL kèm pgvector:** Lưu trữ dữ liệu quan hệ và vector embeddings cho AI.
* **GoTrue Auth:** Xác thực qua email, mạng xã hội OAuth và magic link.
* **PostgREST:** Tự động tạo RESTful API trực tiếp từ bảng database.
* **Realtime Server:** Kết nối WebSocket đồng bộ dữ liệu tức thời.
* **Storage Engine:** Lưu trữ file chuẩn tương thích S3.
* **Supabase Studio:** Giao diện web quản trị cơ sở dữ liệu mạnh mẽ.
