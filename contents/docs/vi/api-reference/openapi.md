---
title: Đặc tả chuẩn OpenAPI 3.0
description: Tài liệu OpenAPI 3.0 tương tác cho các nhà phát triển tích hợp hệ thống.
---

Toàn bộ đặc tả API được tự động tạo tại endpoint:

```text
/api/v1/openapi.json
```

Bạn có thể nhập URL này vào Postman, Insomnia, hoặc các công cụ sinh mã tự động như `openapi-typescript` để tạo client SDK hoàn chỉnh.
